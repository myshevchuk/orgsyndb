## ADDED Requirements

### Requirement: Live task list
`/lab/tasks/` SHALL implement live list updates (web-app "Live lists"):

- Its filter form (`#filters`) updates `#task-rows` in place with `morph:outerHTML` (each row carrying stable `id="task-row-<pk>"`) and updates `#task-counts` out of band with `#task-counts:morph`, using `hx-get="/lab/tasks/"`, `hx-push-url="true"`, `hx-sync="#main:replace"`, and scoped triggers (`submit`, `search from:#filter-q`, `input delay:200ms from:#filter-q`, `change target:select`) while keeping its `method="get"`, `action="/lab/tasks/"`, and submit button for no-script use.
- Its view returns the complete page for plain GET requests and HTMX history restores (`HX-Request: true` with `HX-History-Restore-Request: true`), varies on `HX-Request` and `HX-History-Restore-Request`, and sets `HX-Push-Url` on non-restore HTMX GET responses to `/lab/tasks/` with cleaned active query parameters: `state` omitted when `active` (default) and included otherwise, normalized `person` (`none` or valid uppercase account initials), valid `priority`, and trimmed non-empty `q`.

#### Scenario: Live filtering and canonical URL on the task list
- **WHEN** a test client requests `/lab/tasks/?state=active&person=kl&priority=bogus&q=+Alpha+`, `/lab/tasks/?state=all&person=none`, `/lab/tasks/?state=running`, `/lab/tasks/?state=bogus`, and `/lab/tasks/?q=no-match` with `HX-Request: true`, and requests `/lab/tasks/?state=running` once with both `HX-Request: true` and `HX-History-Restore-Request: true` and once without HTMX headers
- **THEN** all responses return complete page markup (`html`, `#main`, table, filter form) and vary on `HX-Request` and `HX-History-Restore-Request`; `#filters` carries `hx-get="/lab/tasks/"`, `hx-push-url="true"`, `hx-sync="#main:replace"`, scoped triggers (`submit`, `search from:#filter-q`, `input delay:200ms from:#filter-q`, `change target:select`), `hx-target="#task-rows"`, `hx-select="#task-rows"`, `hx-swap="morph:outerHTML"`, and unique disjoint `hx-select-oob="#task-counts:morph"`; populated `#task-rows` rows carry `id="task-row-<pk>"`, the state-filtered response keeps counts across all states in `#task-counts`, and the empty search renders an addressable empty `#task-rows`; the five ordinary HTMX responses set `HX-Push-Url` to `/lab/tasks/?person=KL&q=Alpha`, `/lab/tasks/?state=all&person=none`, `/lab/tasks/?state=running`, `/lab/tasks/`, and `/lab/tasks/?q=no-match`; and the history-restore and plain GET responses omit `HX-Push-Url`
