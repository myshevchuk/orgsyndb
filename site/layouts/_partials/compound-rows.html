{{- /* Returns the records of the compound catalogue's rows: one dict per entry of the registry, ordered by shown name, holding key, the entry's key; name, its shown name (compound-name.html); compound, the entry; made and used, the numbers of published procedures that make the compound and that use it as a substrate, over every entry of a general procedure, each procedure counted once; text, the name, name_de, formula, CAS number, SMILES and the values of the text fields with search = true that the entry sets, joined by single spaces; and values, for each field declared with facet = true or tabs = true, a slice of machine values: "true" or "false" for a boolean, each value set and each of its ancestors, once, for a choice; empty when the entry does not set the field.
